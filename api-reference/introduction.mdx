The AI Forge API gives you programmatic access to every resource in your workspace — from spinning up multi-agent projects to sending messages, reading files, executing terminal commands, and streaming live activity events. Whether you are building a CI/CD integration, a custom dashboard, or an automated testing pipeline, the API exposes the same capabilities you interact with in the UI.

## Base URL

All API requests target the following base URL:

```
https://api.aiforge.app/api
```

Every endpoint is served under `/api`. When breaking changes are introduced, a migration guide will be announced in advance.

## Authentication

The API uses Bearer token authentication. Include your API token in the `Authorization` header on every request:

```
Authorization: Bearer <your-api-token>
```

You can generate and manage your tokens in **Settings → API Tokens**. See the [Authentication](/api-reference/authentication) page for full details.

## Rate Limits

All endpoints are rate-limited to protect service stability. When you exceed the allowed request rate, the API returns a `429 Too Many Requests` response. Implement exponential back-off in your client and respect the `Retry-After` header included in 429 responses to avoid disruptions.

## Error Format

Every error response uses a consistent JSON envelope:

```json
{
  "error": {
    "code": "string",
    "message": "string"
  }
}
```

| Status | Meaning |
|--------|---------|
| `400` | Bad Request — your request body or parameters are invalid |
| `401` | Unauthorized — missing or invalid API token |
| `403` | Forbidden — your token lacks permission for this resource |
| `404` | Not Found — the requested resource does not exist |
| `429` | Too Many Requests — you have exceeded the rate limit |
| `500` | Internal Server Error — something went wrong on our side |

## Quick Start

The examples below show how to list your projects using both `curl` and the browser `fetch` API.

### curl

```bash title="List projects with curl"
curl https://api.aiforge.app/api/projects \
  -H "Authorization: Bearer <your-api-token>"
```

### fetch

```js title="List projects with fetch"
const response = await fetch("https://api.aiforge.app/api/projects", {
  headers: {
    Authorization: "Bearer <your-api-token>",
  },
});

const { projects } = await response.json();
console.log(projects);
```

### Example response

```json title="200 OK"
{
  "projects": [
    {
      "id": "proj_01hw3k9z2x",
      "name": "Customer Support Bot",
      "description": "Multi-agent pipeline for tier-1 support triage",

    },
    {
      "id": "proj_01hw3m7q4r",
      "name": "Code Review Assistant",
      "description": null,
      "createdAt": "2024-05-12T14:23:11Z"
    }
  ]
}
```

## API Surface

The table below is a complete index of every public endpoint. Follow the links to the detailed reference pages for parameter schemas and example responses.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/projects` | List all projects |
| `POST` | `/api/projects` | Create a project |
| `GET` | `/api/projects/:id/files` | List files in a project workspace |
| `POST` | `/api/files` | Create, update, or delete a file |
| `GET` | `/api/agents` | List agents (optionally filter by project) |
| `POST` | `/api/agents` | Create an agent |
| `PATCH` | `/api/agents/:id` | Update an agent |
| `GET` | `/api/chatrooms` | List chatrooms |
| `POST` | `/api/chatrooms` | Create a chatroom |
| `POST` | `/api/messages` | Send a message to a chatroom |
| `GET` | `/api/providers` | List available AI providers |
| `POST` | `/api/credentials` | Store a provider credential |
| `POST` | `/api/terminal/execute` | Execute a shell command |
| `GET` | `/api/activity` | Query paginated activity events |
| `GET` | `/api/tasks` | List background tasks for a project |
