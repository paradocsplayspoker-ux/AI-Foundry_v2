The Terminal API gives you programmatic access to the shell environment inside your AI Forge project. You can run arbitrary commands — useful for tasks like running tests, building packages, starting long-lived servers, or automating environment setup as part of a deployment pipeline.

<Warning>
  Terminal execution requires the following conditions to be met:

  1. The calling agent must have the `execute_commands` permission enabled in its [permission matrix](/api-reference/agents#the-agent-object).
  2. The project must not be in `SAFE_MODE` execution mode.

  Requests that do not meet these conditions will receive a `403 Forbidden` response. Configure agent permissions via the [Agents API](/api-reference/agents) and the project execution mode via [project settings](/api-reference/projects#execution-modes).
</Warning>

<Note>
  Agents that need to install packages (for example, `npm install` or `pip install`) also require the `install_packages` permission to be enabled, in addition to `execute_commands`.
</Note>

---

## Execute a command

Run a shell command inside the project environment and receive its output. Commands are executed in a sandboxed shell with access to the project file workspace.

```
POST /api/terminal/execute
```

Command execution is synchronous — the request blocks until the command completes or the `timeout` is reached. For long-running processes such as servers or watchers, start them as a background process (for example, append `&` in bash) and manage them via your own process tracking.

### Request body

<ParamField body="projectId" type="string" required>
  The ID of the project in whose environment the command should run.
</ParamField>

<ParamField body="command" type="string" required>
  The shell command to execute (for example, `"npm test"` or `"python scripts/ingest.py"`). Commands run in the project root directory by default.
</ParamField>

<ParamField body="timeout" type="integer">
  Maximum time in seconds to wait for the command to complete before forcibly terminating it. Defaults to `30`. Maximum is `300` (5 minutes).
</ParamField>

### Example request

```bash title="Run the test suite"
curl -X POST https://api.aiforge.app/api/terminal/execute \
  -H "Authorization: Bearer <your-api-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "projectId": "proj_01hw3k9z2x",
    "command": "npm test -- --ci --coverage",
    "timeout": 120
  }'
```

### Example response

```json title="200 OK"
{
  "exitCode": 0,
  "stdout": "PASS src/__tests__/auth.test.ts\nPASS src/__tests__/api.test.ts\n\nTest Suites: 2 passed, 2 total\nTests:       18 passed, 18 total\nCoverage:    87.4%\n",
  "stderr": "",
  "timedOut": false,
  "duration": 14.3
}
```

### Response fields

<ResponseField name="exitCode" type="integer">
  The process exit code. `0` indicates success; any non-zero value indicates a failure.
</ResponseField>

<ResponseField name="stdout" type="string">
  Standard output captured from the command.
</ResponseField>

<ResponseField name="stderr" type="string">
  Standard error output captured from the command.
</ResponseField>

<ResponseField name="timedOut" type="boolean">
  `true` if the command was terminated because it exceeded the `timeout` value.
</ResponseField>

<ResponseField name="duration" type="number">
  Wall-clock time in seconds the command took to execute.
</ResponseField>

### Error cases

| Status | Code | Cause |
|--------|------|-------|
| `400` | `validation_error` | `projectId` or `command` is missing, or `timeout` exceeds the maximum. |
| `403` | `forbidden` | The agent lacks `execute_commands` permission, or the project is in `SAFE_MODE`. |
| `404` | `not_found` | The specified `projectId` does not exist. |
| `408` | `timeout` | The command exceeded the timeout and was forcibly terminated. |

<Tip>
  Commands that exit with a non-zero `exitCode` still return a `200 OK` HTTP response — the exit code is part of the response body. Only API-level failures (authentication errors, permission issues, etc.) return non-2xx HTTP status codes.
</Tip>

## Workflow example: build, test, and deploy

```js title="Run a build pipeline"
const BASE = "https://api.aiforge.app/api";
const PROJECT_ID = "proj_01hw3k9z2x";
const TOKEN = process.env.AIFORGE_API_TOKEN;

async function run(command, timeout = 60) {
  const res = await fetch(`${BASE}/terminal/execute`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ projectId: PROJECT_ID, command, timeout }),
  });
  return res.json();
}

// Install dependencies
const install = await run("npm ci", 120);
if (install.exitCode !== 0) throw new Error(install.stderr);

// Run tests
const test = await run("npm test -- --ci", 180);
if (test.exitCode !== 0) throw new Error(`Tests failed:\n${test.stdout}`);
console.log(test.stdout);

// Build for production
const build = await run("npm run build", 120);
if (build.exitCode !== 0) throw new Error(`Build failed:\n${build.stderr}`);
console.log("Build succeeded.");
```
