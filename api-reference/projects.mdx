Projects are the primary organizational unit in AI Forge. Every agent, chatroom, and file belongs to a project. The Projects API lets you create projects, list all projects your token can access, and browse the file workspace inside any project — making it straightforward to automate workspace provisioning from your own tooling or deployment pipelines.

## The project object

<ResponseField name="id" type="string">
  Unique identifier for the project, prefixed with `proj_`.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable project name.
</ResponseField>

<ResponseField name="description" type="string | null">
  Optional description of the project's purpose.
</ResponseField>

<ResponseField name="executionMode" type="string">
  Controls how agent-proposed changes are applied. One of `ASK_BEFORE_CHANGES` (review each diff before it lands), `AUTO_APPLY` (changes are applied immediately), or `SAFE_MODE` (changes are staged for manual review and cannot be auto-applied).
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 timestamp of when the project was created.
</ResponseField>

## List projects

Retrieve all projects accessible to your API token.

```
GET /api/projects
```

This endpoint returns every project your account can access. The list is ordered by creation date, newest first.

### Example request

```bash title="List all projects"
curl https://api.aiforge.app/api/projects \
  -H "Authorization: Bearer <your-api-token>"
```

### Example response

```json title="200 OK"
{
  "projects": [
    {
      "id": "proj_01hw3k9z2x",
      "name": "Customer Support Bot",
      "description": "Multi-agent pipeline for tier-1 support triage",
      "executionMode": "ASK_BEFORE_CHANGES",
      "createdAt": "2024-05-10T09:00:00Z"
    },
    {
      "id": "proj_01hw3m7q4r",
      "name": "Code Review Assistant",
      "description": null,
      "executionMode": "AUTO_APPLY",
      "createdAt": "2024-05-12T14:23:11Z"
    }
  ]
}
```

## Create a project

Create a new project in your workspace.

```
POST /api/projects
```

### Request body

<ParamField body="name" type="string" required>
  The name of the project. Must be between 1 and 100 characters.
</ParamField>

<ParamField body="description" type="string">
  An optional description for the project. Maximum 500 characters.
</ParamField>

<ParamField body="executionMode" type="string">
  Controls how agent-proposed file changes are handled. One of `ASK_BEFORE_CHANGES` (default), `AUTO_APPLY`, or `SAFE_MODE`. See the [execution modes](#execution-modes) section below.
</ParamField>

### Example request

```bash title="Create a project"
curl -X POST https://api.aiforge.app/api/projects \
  -H "Authorization: Bearer <your-api-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Data Analysis Pipeline",
    "description": "Automated data ingestion and reporting agents",
    "executionMode": "ASK_BEFORE_CHANGES"
  }'
```

### Example response

```json title="201 Created"
{
  "project": {
    "id": "proj_01hwab3p8n",
    "name": "Data Analysis Pipeline",
    "description": "Automated data ingestion and reporting agents",
    "executionMode": "ASK_BEFORE_CHANGES",
    "createdAt": "2024-05-14T11:05:32Z"
  }
}
```

### Error cases

| Status | Code | Cause |
|--------|------|-------|
| `400` | `validation_error` | `name` is missing, exceeds the character limit, or `executionMode` is not a recognised value. |
| `401` | `unauthorized` | Invalid or missing API token. |

## List project files

List the files and directories inside a project's workspace.

```
GET /api/projects/:id/files
```

File paths are always relative to the project root (for example, `src/main.py` or `data/input.csv`). To read or write file content, use the [Files API](/api-reference/files).

### Path parameters

<ParamField path="id" type="string" required>
  The unique ID of the project (for example, `proj_01hw3k9z2x`).
</ParamField>

### Query parameters

<ParamField query="path" type="string">
  The directory path to list, relative to the project root. Defaults to `/` (the project root). For example, `path=src` lists the contents of the `src/` directory.
</ParamField>

### Example request

```bash title="List files at the project root"
curl "https://api.aiforge.app/api/projects/proj_01hw3k9z2x/files?path=/" \
  -H "Authorization: Bearer <your-api-token>"
```

### Example response

```json title="200 OK"
{
  "path": "/",
  "entries": [
    {
      "name": "README.md",
      "type": "file",
      "size": 1024,
      "updatedAt": "2024-05-14T10:00:00Z"
    },
    {
      "name": "src",
      "type": "directory",
      "size": null,
      "updatedAt": "2024-05-14T11:30:00Z"
    },
    {
      "name": "data",
      "type": "directory",
      "size": null,
      "updatedAt": "2024-05-13T08:45:00Z"
    }
  ]
}
```

### Error cases

| Status | Code | Cause |
|--------|------|-------|
| `404` | `not_found` | No project with the given ID exists, or your token cannot access it. |

## Execution modes

Every project has an `executionMode` that governs how agent-proposed file changes are handled. You can set this at creation time or update it in your project settings in the UI.

| Mode | Behaviour |
|------|-----------|
| `ASK_BEFORE_CHANGES` | The agent presents a diff for your review before any file is written or deleted. You approve or reject each change. |
| `AUTO_APPLY` | Agent-proposed changes are applied to the workspace immediately without requiring approval. |
| `SAFE_MODE` | All changes are staged for manual review and cannot be applied automatically, even if an agent requests it. Intended for high-risk environments. |

<Warning>
  Setting a project to `AUTO_APPLY` means agents with `write_files` or `delete_files` permissions can modify your workspace without prompting you first. Use this mode only in sandboxed or non-critical projects.
</Warning>
