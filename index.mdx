AI Forge is a collaborative development environment where you direct a team of AI agents — each with its own role, model, and permissions — to work together on real software projects. Agents read and write actual files, run commands in a live terminal, review each other's code, and stream every action back to you in real time.

## How AI Forge Works

AI Forge connects three layers into one seamless loop: **your intent**, **your agent team**, and **your project**.

<Steps>
  <Step title="Create a Project">
    Set up a persistent project workspace. Every project has its own isolated filesystem, file history, and agent team.
  </Step>
  <Step title="Add AI Agents">
    Build a team by creating agents with distinct roles (Architect, Developer, Security, QA, etc.), assigning each a provider and model, and configuring their permissions.
  </Step>
  <Step title="Give Your Team an Objective">
    Type an instruction in the chatroom. Agents collaborate, read and write real project files, execute terminal commands, and stream every action to your activity feed.
  </Step>
  <Step title="Review & Iterate">
    Inspect proposed file changes as unified diffs, accept or reject them, and guide the team toward completion — all without leaving AI Forge.
  </Step>
</Steps>

  </Card>
  <Card title="Live Terminal" icon="terminal">
    A genuine shell bound to your project root. Agents and humans run the same commands.
  </Card>
  <Card title="Multi-Provider Support" icon="plug">
    Connect OpenAI, Anthropic, Gemini, Groq, xAI, OpenRouter, and more — mix models across agents.
  </Card>
  <Card title="Agent Permissions" icon="shield-halved">
    Control exactly what each agent can read, write, delete, execute, and access on the network.
  </Card>
  <Card title="Real-Time Activity" icon="bolt">
    Every tool call, file change, and terminal command streams live to your activity feed.
  </Card>
  <Card title="Diff Review" icon="code-compare">
    AI-proposed edits surface as reviewable diffs. Accept, reject, or restore any version.
  </Card>
</CardGroup>

<Note>
  AI Forge enforces a strict **no-mock** guarantee. Every agent response comes from a real provider, every file operation touches the real filesystem, and every terminal command runs in a real shell process.
</Note>
